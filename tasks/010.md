# 010 — Tela de Pessoas (People)

## Objetivo

Criar a tela de gestão de "Pessoas". No sistema, uma `Person` atua como uma etiqueta (label) ou contato ("Eu", "Mãe", "João", "Amigos") para atribuir partes de uma transação a alguém específico através dos splits (`TransactionSplit`). Esta tela permitirá o cadastro e a manutenção dessa lista de nomes.

## Contexto

- **Rota:** `src/app/[locale]/(app)/people/`
- **Modelo Principal (Prisma):** `Person` (e sua relação com `TransactionSplit`).
- **Regras de Negócio:**
  - Uma `Person` é apenas um nome vinculado ao usuário logado, não é uma conta de login.
  - A divisão de gastos (quem deve o que) acontece no momento de criar uma transação, onde o valor total é dividido entre várias `Person`s. 
  - Nesta tela inicial não haverá cálculo complexo de "saldo devedor" de cada pessoa (isso será parte de uma funcionalidade futura de relatórios ou acertos de contas), o foco é puramente no cadastro (CRUD).

## Recursos

### 1. Lista de Pessoas
- Visualização simples em lista ou cards.
- Mostrar o nome cadastrado.
- Menu de contexto (editar, excluir).
- Regra de exclusão: Como `TransactionSplit` está configurado com `onDelete: Cascade` no schema (em relação à pessoa), excluir uma pessoa apagaria silenciosamente a atribuição da dívida nas transações passadas. **Importante:** Pode ser interessante adicionar uma validação (via action) que impeça a exclusão caso a pessoa já tenha splits vinculados, ou ao menos mostre um aviso rigoroso de confirmação antes de excluir.

### 2. Formulário de Criação/Edição (Sheet)
- Campos base: **Nome** (obrigatório, string simples).

## Passos

1. **`schema.ts`**: Criar esquemas Zod (ex: `personSchema`).
2. **`actions.ts`**: Implementar Server Actions:
   - `listPeople()`: Busca todas as `Person`s do usuário logado. Opcionalmente contar quantos splits cada pessoa tem para alertar na exclusão.
   - `createPerson(data)` / `updatePerson(id, data)`: Salvar/editar a pessoa.
   - `deletePerson(id)`: Validar se existem transações vinculadas e apagar.
3. **`_components/`**:
   - `people-view.tsx`: Listagem das pessoas cadastradas.
   - `form/person-sheet.tsx`: Formulário de criação/edição.
4. **Mensagens (`scrn-people.json`)**: 
   - Adicionar traduções (pt-BR e en) para a nova tela. Seguindo o padrão `AGENTS.md`.

## Pronto quando

- A tela `/people/` listar corretamente os nomes cadastrados.
- For possível criar, editar e excluir uma pessoa.
- Impedir (ou alertar claramente sobre) a exclusão de uma pessoa que já possua despesas vinculadas (`TransactionSplit`).
- Nenhum texto hardcoded, tudo passando pelo `next-intl`.
- `pnpm lint` e `pnpm build` sem erros.
