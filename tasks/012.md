# Planejamento: Tela de Recorrências

Criar a tela de gestão de recorrências (`/recurrences`), permitindo ao usuário listar, editar e excluir regras de recorrência (`Recurrence` no Prisma). 

A arquitetura e a responsividade seguirão estritamente o padrão estabelecido na tela de Transações:
- **Server Actions + TanStack Query** para busca e mutação.
- **Design responsivo (Mobile First):** `DataTable` no desktop e uma lista de cards no mobile (`md:hidden`), como estipulado na task 011.
- **Sheet/Drawer (Vaul)** para os formulários de criação/edição.
- **Internacionalização (i18n):** Criação do namespace `scrn-recurrences.json`.

## User Review Required

> [!IMPORTANT]
> A tela de Transações filtra os dados pelo mês atual. Regras de recorrência, por outro lado, são contínuas (atravessam meses). A listagem inicial trará todas as recorrências ativas por padrão, com opção de ver as inativas/finalizadas nos filtros.

## Open Questions

> [!WARNING]
> Precisamos definir as regras de negócio para edição e exclusão de uma recorrência:
> 
> 1. **Edição:** Se o usuário editar o valor de uma recorrência (ex: de R$ 50 para R$ 60), o sistema deve atualizar automaticamente todas as transações *futuras/pendentes* vinculadas a ela?
> 2. **Exclusão:** Ao apagar uma regra de recorrência, o que acontece com as transações geradas por ela? Deletamos apenas as futuras/pendentes, ou nenhuma (a regra deixa de existir, mas os registros ficam)?
> 3. **Summary Cards:** Na tela de transações temos os cards de Receita, Despesa e Saldo do mês. Na tela de recorrências, você gostaria de exibir cards com o "Impacto Mensal Fixo" (soma das receitas recorrentes vs despesas recorrentes)?

### Arquitetura de Roteamento e Ações

#### [NEW] [page.tsx](file:///c:/dev/fi-sync/src/app/[locale]/(app)/recurrences/page.tsx)
Página server-side. Fará o fetch inicial (SSR) das recorrências e das opções do formulário (contas e categorias) para injetar no client component e evitar loading states na primeira renderização.

#### [NEW] [actions.ts](file:///c:/dev/fi-sync/src/app/[locale]/(app)/recurrences/actions.ts)
Server Actions da rota:
- `listRecurrences(filters)`: Busca as regras.
- `createRecurrence(data)` / `updateRecurrence(id, data)`: Salva a regra.
- `deleteRecurrence(id)`: Exclui a regra (sujeito à resposta da pergunta acima).
- `getRecurrenceFormOptions()`: Retorna as opções para os selects.
